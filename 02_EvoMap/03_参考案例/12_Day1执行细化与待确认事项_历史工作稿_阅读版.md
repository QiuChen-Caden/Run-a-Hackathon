**四、环节执行卡**

**环节 1｜签到打卡（13:30–14:30 · 已定）**

**流程：**入口签到 →（互动装置打卡）→ 领取 Ghost ID + 自选 Skill Tag（CODE/IDEA/VISUAL/PRODUCT/MAKER/PITCH，1–2 个）→ 工作人员将 Skill Tag 粘贴于选手**醒目位置**（主办统筹及预算批准人要求：避免 ID 卡背面不易查看）→ 按 Ghost Zone 引导入场。

**互动装置（理想态）：**悬吊球节脑机接口电线 + 头盔拍照装置，攻壳风打卡点，兼顾传播素材采集。

**备案 A（装置不可行/减配）：**改为主题背景板 + 道具头盔拍照框，保留拍照传播能力。

**备案 B（妆造保留场景）：**志愿者在签到时段按需指引快速主题化妆，不强制、不单独排时段（妆造去留为待定项 \#1）。

**备案 C（人流峰值）：**按 Zone 分流签到台；Skill Tag 预选二维码提前随报名/到场提醒推送，压缩现场选择耗时。

**待定：**签到系统是否支持 Skill Tag 自选并生成唯一 ID（#10）；打卡装置搭建方与成本（#11 场地核）；13:30 前早到与 15:00 后迟到补签方案（#6）。
