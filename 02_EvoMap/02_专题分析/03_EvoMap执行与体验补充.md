## 3. 日程与门禁产生的硬约束

早期 Day1 细化稿为签到 13:30 至 14:30、40 分钟破冰、75 分钟开幕、约 16:30 开发启动，Day3 派对到 22:00、Day4 到 24:00 清场。后续 ToDo 的 9 月 12 日口径改为每天 20:00 场馆封锁、派对提前到 18:00 至 19:30、开场后 20:00 开发开始，并取消夜宵。这类变化会同时影响晚到人员、洗澡、晚餐、外卖、工作人员换班、供应商、派对和撤场。

ToDo 同一文件仍残留 16:30 至 18:30 与 17:00 至 19:00 两版开幕、19:30 与 22:30 两版过夜区开放、已取消夜宵与 22:00 夜宵行。因此，它是版本演变材料，不能直接发给现场执行者。

## 5. Ghost ID 的价值与落地限制

9 月 3 日身份载体草案发现三套系统重叠：签到腕带、破冰 Ghost ID 与 Skill Tag、交友号牌与同号贴纸。建议保留腕带作入场和角色凭证，让 Ghost ID 兼任社交编号，取消独立交友号牌，由报名系统映射“报名人、腕带号、G 编号”。

| 功能 | 历史建议 | 复办验收 |
|---|---|---|
| 身份与进出 | 七色防拆腕带、角色胸牌 | 颜色与可进入区一致；补发与遗失处理清楚 |
| 破冰 | 随机身份供聊天，不先比较履历 | 身份内容可理解、不强迫参与，有安静旁观选项 |
| 组队 | 自选 1 至 2 个 Skill Tag，能力互补 | 标签醒目，设计稿与实际佩戴效果验证 |
| 交友、互评、礼物 | G-001 至 G-500 为全场编号，小贴纸共用 | 号码唯一，实名映射只给必要工作人员，丢卡不产生重复身份 |
| 流量 | 身份、标签和贴纸随选手包一次发 | 实测领包时长，避免重复排队 |
| 系统降级 | 小程序、纸质看板、人工 OPEN NODE | 纸质登记可恢复成唯一队伍表，无队人员有私人补位 |

## 10. 下一位学生主办者可直接复用的验收卡

以下为建议，按自己规模与场地改写，不能直接抄 500 人配置。

1. **体验卡：**服务对象、需求、可获得资源、数量、地点、时段、责任人和备用方式。分别列参赛者、嘉宾、合作方、工作人员；食物在现场与人人拿得到分别验收。
2. **身份卡：**公开角色、通行权限、活动唯一编号、后台实名映射、补发、丢失和纸质降级；统一编号避免三本账。
3. **夜间卡：**真实可过夜人数、床位与分区、厕所、洗澡、门禁、值守、贵重物品与路径。先验证容量再承诺。
4. **设备卡：**设备、提供方、领取人、状态、配件、必要培训、异常联系人、归还时刻和签回。公共器材与个人设备分开。
5. **内容卡：**事实源、主创批准、稿件版本、视觉尺寸、权限、导出及播放实测；所有权益都有能兑现的实施方。
6. **人员卡：**实名、岗位、时段、电话、替补、入场方式和交接。专业保障由对应专业人员实施，学生总控负责协调与验收。
7. **结果卡：**实际签到、组队、提交、评审覆盖、颁奖、设备归还、影像和授权状态；最终结果用日志和凭据证明。
